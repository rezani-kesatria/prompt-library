# 03 · Content & SEO copywriting

Write the actual words — in the brand's voice, SEO-optimised, surfacing the brand
values — to the exact slots the page spec defines. Brand voice and SEO are the
*same* sentences, not two passes.

**Hand-off**
- **In:** the brand values (**00**), the charter's tone (**01**), and the section
  slots + length limits (**02**).
- **Out:** final per-slot copy + SEO meta (title, description) + image alt-text drafts.
- **Next:** the strings fill **02**'s spec and land in **05**'s build (and later
  become editable Text modules at **06**).

**When to use** — after the page spec (02) exists, so copy is written to real slots
with real length caps. This is a feeder into 02 and 05, not a spine phase.

---

## Fill-in template

```
Write the {home}-page copy for {Company} in their brand voice, SEO-optimised.

Voice: {elegant, assured, plain-spoken}; {UK / US} spelling; short sentences;
no hype words ({"cutting-edge", "world-class", "synergy"}). Surface the brand
values: {value 1}, {value 2}, {value 3}.

SEO: primary keyword "{keyword}", secondaries {…}; exactly one H1; descriptive H2s
per section; a meta title (≤60 chars) + meta description (≤155 chars); location
intent: {city / region}. Read naturally first — no keyword stuffing.

Deliver copy per section slot from the 02 spec:
- Hero: H1 (≤{9} words) + sub ({1} line) + CTA label.
- Intro: {1} paragraph (≤{66} words).
- {Services}: {3}× {title + 1 line}.
- {Proof}: a {1}-line testimonial lead-in.
- … + meta title, meta description, and alt-text drafts for every image.
```

## Filled example — GreenGarden

```
Write the home-page copy for GreenGarden Integrated Services in their brand voice,
SEO-optimised.

Voice: elegant, assured, plain-spoken; UK spelling; short sentences; no hype words.
Surface the values: craftsmanship, stewardship, longevity.

SEO: primary keyword "landscaping Malaysia"; secondaries "garden design",
"grounds maintenance", "commercial landscaping"; one H1; descriptive H2s; meta
title ≤60, meta description ≤155; location intent: Klang Valley / Malaysia.

Deliver per 02 slots:
- Hero H1 (≤9 words): "Gardens built to last a generation." + sub + CTA
  "Request a consultation".
- Intro: one 60-word paragraph on the design–build–maintain promise.
- Services: Design / Build / Maintain — title + one line each.
- Proof: a 25-word testimonial lead-in.
- CTA band headline + meta title + meta description + alt-text for every
  hero/card/showcase image.
```

## Do's

- **DO** write to the exact slots and length limits from the **02** spec — copy
  that overflows the layout breaks the composition.
- **DO** surface the named brand values explicitly but naturally — the SEO and the
  brand voice should be the same sentences.
- **DO** give exactly one H1, descriptive H2s, and real alt-text — this is where
  a11y (**07**) and SEO are won together.
- **DO** keep the meta title ≤60 and the description ≤155 characters.

## Don'ts

- **DON'T** keyword-stuff or use the hype words the brief banned — it reads cheap
  and hurts ranking.
- **DON'T** write past the slot — the measure (66ch) and word caps are load-bearing.
- **DON'T** invent facts or claims that aren't in the profile PDF — client review
  will bounce them.
- **DON'T** leave placeholder lorem for 05 to inherit — an unfilled slot is a
  02/03 gap to close, not a build problem.
