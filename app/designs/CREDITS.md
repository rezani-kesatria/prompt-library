# Credits & references

Every design in this library began as someone else's work. The recreations here exist to
**extract and document a design language** — the rule set behind a layout — so that it can be
carried into a prompt without an agent inventing the gaps. They are study exercises and internal
reference material, not products, and not a claim on anyone's design.

**If you use one of these as a starting point, the credit belongs to the designer below.**
Please go look at the original — it is better than the recreation.

Sources are Dribbble shots unless marked *(Muzli)*. Attribution is taken from each shot's own
byline (`<work> by <designer> for <studio>`), verified against the live page rather than from
memory — never reconstructed from a URL slug or a filename.
